# The fonts of the brand

The fonts the scene and the social previews are drawn with, so that they render the same on every
machine. They are the window's own faces, the same files as the `assets/fonts/` of the kit
(`gpui-design-system`); `OFL.txt` is the fonts' licence a build ships (`tools/package.sh`).

| Font | Files | Licence | Source |
|---|---|---|---|
| Geist, the text | `Geist-{Regular,Medium,SemiBold}.ttf` (version 1.802) | SIL Open Font License 1.1, `OFL.txt` | The Geist Project Authors, https://github.com/vercel/geist-font |
| Geist Mono, the labels, calls and states | `GeistMono-{Regular,Medium}.ttf` (version 1.802) | SIL Open Font License 1.1, `OFL.txt` | The Geist Project Authors, https://github.com/vercel/geist-font |
